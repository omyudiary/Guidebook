# 오뮤다이어리 가이드북

오뮤다이어리에서 구매해 주셔서 감사합니다.

처음 사용하시는 분들을 위해 **필기 앱의 기본 사용법**을 담았습니다.
가이드북의 내용은 오뮤다이어리의 전체 상품에 대한 **공통 가이드북**입니다.

각 필기 앱마다 사용 방법은 다르나 사용하는 패턴은 비슷합니다.
가이드북에 나와있는 5가지 앱 이외에도 참고하신다면 도움이 되실 거예요!
