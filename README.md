# 오뮤다이어리 가이드북

오뮤다이어리에서 구매해 주셔서 감사합니다.

처음 사용하시는 분들을 위해 **필기 앱의 기본 사용법**을 담았습니다.
가이드북의 내용은 오뮤다이어리의 전체 상품에 대한 **공통 가이드북**입니다.

각 필기 앱마다 사용 방법은 다르나 사용하는 패턴은 비슷합니다.
가이드북에 나와있는 5가지 앱 이외에도 참고하신다면 도움이 되실 거예요!

## 사용하시는 앱을 선택해 주세요

| 필기 앱 |
| --- |
| [굿노트 (Goodnotes)](goodnotes/README.md) |
| [노타빌리티 (Notability)](notability/README.md) |
| [노트쉘프 (Noteshelf)](noteshelf/README.md) |
| [삼성노트 (Samsung Notes)](samsung-notes/README.md) |
| [소도 (Xodo)](xodo/README.md) |

{% hint style="info" %}
아이패드에서 굿노트·노타빌리티를 쓰신다면 파일은 꼭 **사파리(Safari)** 에서 다운로드해 주세요.
{% endhint %}

사용하시면서 궁금한 점이 있으시면 언제든지 문의해 주세요!
행복한 하루 되세요 😊
