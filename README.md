# 🍒 Welcome to omyudiary

오뮤다이어리를 선택해 주셔서 감사합니다.\
이 가이드북에는 상품 다운로드 방법부터 필기 앱 사용법, 폰트 설치 방법까지\
디지털 노트를 사용하는 데 필요한 모든 안내가 담겨 있어요.\
오뮤다이어리의 **모든 디지털 상품에 공통으로 적용되는 가이드**이니, 처음 사용하신다면 꼭 확인해 주세요!

{% hint style="info" %}
**처음 사용하시나요?** 아래 순서대로 따라오시면 가장 빠르게 시작할 수 있어요.

1. 구매하신 파일을 [PDF 다운로드](download/pdf.md)한 후, 사용하실 기기에 저장해 주세요.
2. 사용 중인 필기 앱의 가이드에서 하이퍼링크 사용법을 먼저 확인해 주세요.
3. 스티커, 표지, 속지 추가 방법 등 궁금한 내용을 확인해 보세요.
{% endhint %}
